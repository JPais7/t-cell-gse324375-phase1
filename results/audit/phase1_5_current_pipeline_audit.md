# Phase 1.5 current pipeline audit

## Audited repository state

- Audit started from `main` commit `2b0e6d194991c05b14bb23d07d9f35c487ca865a`.
- Scripts 01–24 were inspected, including refinement, activation, data-driven states, pseudobulk, interaction discovery, temporal support, TF activity, ranking, LOOCV/null, biological annotation and QC.
- Primary dataset: GSE324375. Contextual external registries: GSE289772 and GSE314342.

## Actual dependency graph

`raw GEO/metadata → manifest/GEX audit → multimodal object/design → atlas → refined T cells → activation RNA/ADT/pathways → source–ligand–receptor hypotheses → expression plausibility → mechanism ranking/experimental contrasts/temporal support → TF and data-driven states → candidate construction → UniProt entity annotation → biological interaction gate → mouse-level LOOCV/sign null → decomposable final ranking → readiness → TOP candidates/report → fail-closed QC`.

## Output provenance and regeneration

The Phase 1.5 terminal outputs are generated by scripts 20–24 and checked by script 21. Upstream stored objects were reused because they are large, already versioned analytical outputs and their schemas remain compatible; raw preprocessing was not repeated merely to change downstream annotation/ranking. Output modification times are checked against their generator scripts. The run manifest records the checked-out code commit.

## Weaknesses and inconsistencies found

1. The earlier biological audit relied heavily on short explicit gene lists.
2. ADAM sheddases could be incorrectly promoted if generic interaction-resource membership overrode molecular role.
3. Directional replication lacked explicit median, mean, IQR and sign of actual per-mouse effects in the stability output.
4. LOOCV used true candidate-specific mice, but its fold-score formula lagged behind the latest final-score definition.
5. Mechanistic coherence was a mean of modality flags rather than explicit chain support.
6. Biological validity and experimental testability were gates but not explicit score dimensions.
7. The previous family key used source plus ligand and could preserve redundant molecular axes.

## Corrections made

- Created a reproducible 1,596-gene mouse UniProtKB annotation table with localization, ligand/receptor, enzyme, TF, metabolic, adhesion and sheddase fields.
- Rebuilt interaction validity as `VALID_LR`, `MEMBRANE_CONTACT`, `SHEDDING_PROCESSING`, `INVALID_LR` or `UNKNOWN`.
- Ensured sheddase logic precedes conventional LR logic and requires an annotated substrate for retention.
- Added direct animal-effect summaries and aligned LOOCV fold scoring with the current decomposable ranking.
- Replaced coherence with `mechanistic_evidence_coherence`, derived from the explicit chain.
- Added biological-validity and non-dominant experimental-testability components, molecular-axis family collapsing, expanded sensitivity and a Phase 2 readiness gate.
- Preserved invalid candidates in audit outputs rather than deleting them silently.

## Remaining limitations

- UniProt annotation establishes molecular identity/localization, not context-specific activity or physical interaction in these tumors.
- Interaction-resource direction and co-expression remain observational.
- No spatial contact, same-animal longitudinal trajectory or direct system-matched perturbation is available.
- The downstream IFNG/TNF–myeloid–tumoricidal mechanism is prior biological context and is not evidence that a ranked upstream candidate causes activation.
- Residual treatment, batch, library composition, abundance, proliferation, survival and stress effects remain possible despite animal-aware analyses.
